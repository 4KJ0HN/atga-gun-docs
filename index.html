ATGA Gun System

Server-authoritative blasters with heat, scopes, akimbo and splash weapons, plus armor, team rules and one damage API shared by guns, NPCs and abilities.

Server-side hits PC & mobile NPC-ready API Armor & teams

Overview

Bolts are simulated on the server and drawn on every client, so hits can't be faked.

Every gun is a normal Tool with a WeaponConfig module inside it. Anything that deals damage, including NPCs, explosions and your own abilities, goes through the same Combat module, so armor and team rules always behave the same way.

Adding a gun

Five steps, and only the first three are required.

  1. Make a Tool with a Handle part. Give the tool a boolean attribute HybridBlaster set to true.
  2. Put an Attachment named Barrel in the Handle where bolts should come out.
  3. Add a ModuleScript named WeaponConfig inside the tool. List only what differs from the defaults.
  4. Optional
    Add sounds to the Handle named ShootSound, AltShootSound, ZoomIn, Equip or Cooled.
  5. Optional
    Set the tool attribute OTSOnly to true to lock it to over-the-shoulder view.
StarterPack › E-11 › WeaponConfig
return {
	FireMode = "Auto",
	Damage = 12,
	HeadMultiplier = 1.5,
	BoltSpeed = 1200,
	FireInterval = 0.25,
	HeatPerShot = 8,
	MaxHeat = 100,
	CoolTime = 2.25,
	Projectile = "BlueLaser",
	ShootVFX = "BlueMuzzle",
}
Tip If a config has a mistake, the gun won't equip and the output names the bad key, for example E-11: invalid FireInterval.

Splash weapons

Give a gun SplashRadius and its bolt explodes on impact, damaging everyone in range with falloff from the center. SplashKnockback shoves whoever it damages.

StarterPack › RPS-6 › WeaponConfig
return {
	FireMode = "Semi",
	Damage = 90,
	Reflectable = false,
	BoltSpeed = 400,
	FireInterval = 1,
	HeatPerShot = 100,
	MaxHeat = 100,
	CoolTime = 12.5,
	SplashRadius = 19,
	SplashMinDamage = 90,
	SplashKnockback = 75,
	Recoil = 0.16,
	ProjectileAcceleration = Vector3.new(0, -24, 0),
	Projectile = "RPS6Rocket",
	ShootVFX = "RPS6Muzzle",
}

Shotguns

Set FireMode = "Shotgun" and each click fires a spread of bolts. Pellets sets how many bolts each shell fires, and Spread sets the width of the cone in degrees. Each pellet deals the full Damage, and heat is added once per shell.

Example · shotgun WeaponConfig
return {
	FireMode = "Shotgun",
	Pellets = 8,
	Spread = 6,
	Damage = 9,
	Range = 120,
	BoltSpeed = 1400,
	FireInterval = 0.8,
	HeatPerShot = 25,
	MaxHeat = 100,
	CoolTime = 3,
	Projectile = "BlueLaser",
	ShootVFX = "BlueMuzzle",
}

Combat API

Server only. Deal damage or fire bolts from any server script with the same rules the blasters use.

GunServer.Modules.Combat
Server Script
local ServerScriptService = game:GetService("ServerScriptService")
local Combat = require(ServerScriptService.GunServer.Modules.Combat)

Damage

Combat.Damage(attacker, target, amount, options?)

Armor takes the hit first and the rest goes to health. The attacker can be a Player, an NPC model, or nil for environment damage. The target can be a Player, a character, or any part inside one.

Options
IgnoreArmorSkip armor and hit health directly.
HeadshotPassed to hooks and the client for the hitmarker color.
PositionWhere the hit landed, for damage numbers. Defaults to the target's root.
SourceThe weapon or thing that caused it, for your own hooks.
Example
local result = Combat.Damage(npcModel, player, 25)

if result.Applied then
	print("armor took", result.ArmorDamage, "health took", result.HealthDamage)
else
	print("blocked:", result.Reason)
end

-- a melee hit that goes straight through armor
Combat.Damage(player, npcModel, 40, { IgnoreArmor = true, Source = saberTool })
Why a hit can be blocked · result.Reason
InvalidTargetNo living humanoid, or not in the workspace.
InvalidAmountThe amount isn't a positive number.
CivilianProtectedTarget is a civilian without KOS.
CivilianRaiderA raider and a civilian tried to hurt each other.
SelfDamageAttacker and target are the same character.
SameTeamSame team, or both Republic, and the attacker lacks CanTeamKill.
ForceFieldThe target has a ForceField.
NoDamageNothing actually changed.
Result fields · also passed to OnDamaged and OnKilled
DamageArmor plus health damage dealt.
ArmorDamage · HealthDamageThe split between the two.
ArmorBrokenThis hit took armor to zero.
ArmorRemaining · HealthRemainingValues after the hit.
Killed · HeadshotWhat happened on this hit.
Reflected · IgnoreArmorReflected means the bolt bounced off a Reflect brick first.
Attacker · AttackerPlayerAttackerPlayer is nil for NPCs. Also AttackerIsPlayer, AttackerName, AttackerUserId.
Target · TargetPlayerTarget is the character model. Also TargetIsPlayer, TargetName, TargetUserId, Humanoid.
Source · PositionWhatever was passed in, and where the hit landed.

CanDamage

Combat.CanDamage(attacker, target) returns allowed, reason using the team and civilian rules, without dealing damage. Handy for NPC targeting.

Example
for _, player in Players:GetPlayers() do
	if Combat.CanDamage(npcModel, player) then
		-- worth shooting at
	end
end

SplashDamage

Combat.SplashDamage(attacker, center, radius, damage, options?)

Full damage at the center, falling off to MinDamage at the edge. Each target goes through Combat.Damage, so armor and team rules still apply. Returns a list of successful results.

Options
MinDamage0Damage at the edge of the radius.
LineOfSighttrueWalls between the center and a target block the damage.
IgnoreArmorfalseSkip armor.
Ignore{}Instances to leave out.
SourcePassed to hooks.
Example · thermal detonator
local hits = Combat.SplashDamage(player, grenade.Position, 15, 80, {
	MinDamage = 20,
	Source = grenade,
})
print(#hits, "targets hit")

FireBolt

Combat.FireBolt(options) returns the bolt's id.

Fires the same bolt the player blasters use. It's simulated on the server, drawn on every client, bounces off Reflect bricks and triggers the usual hit feedback.

Options
OriginRequiredWhere the bolt starts.
DirectionRequiredWhich way it flies. Doesn't need to be a unit vector.
Config or WeaponRequiredConfig needs Damage, BoltSpeed and Range, and accepts any combat or visual key above. Add Pellets and Spread for a shotgun blast. Or pass a Weapon tool with a WeaponConfig.
AttackerWho gets credit. A Player, an NPC model, or nil.
IgnoreInstances the bolt passes through, like the NPC's own model.
IgnoreArmorForce armor-piercing for this shot.
SourcePassed to hooks. Defaults to the weapon, then the attacker.
Example · NPC trooper
local muzzle = npcModel.Blaster.Barrel.WorldPosition
local target = player.Character.HumanoidRootPart

Combat.FireBolt({
	Attacker = npcModel,
	Origin = muzzle,
	Direction = target.Position - muzzle,
	Config = {
		Damage = 15,
		BoltSpeed = 900,
		Range = 500,
		Projectile = "RedLaser",
		ShootVFX = "RedMuzzle",
	},
	Ignore = { npcModel },
})

SetArmor

Combat.SetArmor(target, amount, maxArmor?) sets armor and the maximum it refills to. Without maxArmor, the maximum equals amount.

Example
Combat.SetArmor(player, 50)        -- 50 armor, refills to 50
Combat.SetArmor(player, 25, 100)   -- 25 now, refills to 100

Armor

A second health bar that soaks damage first and refills on its own.

RefillAfter 30 seconds without damage, armor refills to its maximum. Every hit restarts the timer.
Starting value0, unless the character has an Armor attribute.
Setting itCombat.SetArmor, or the Armor and MaxArmor attributes.
PiercingHits with IgnoreArmor leave armor alone and go straight to health.
FeedbackArmor hits get their own hitmarker color, and client events include ArmorDamage.

Team rules

Checked on every hit: bolts, splash and direct Combat.Damage calls.

Players use their Roblox Team. NPCs use a Team string attribute on their model.

CiviliansCan't be damaged by anyone. Override: KOS on the civilian.
Raiders × CiviliansCan't damage each other, in either direction.
Same teamCan't damage each other. Override: CanTeamKill on the attacker.
RepublicEvery team in RepublicTeams is one side, so they can't damage each other. Override: CanTeamKill.
Reflected boltsIgnore every rule above and can hit anyone, including the shooter.
Example
player:SetAttribute("KOS", true)          -- this civilian can now be shot
player:SetAttribute("CanTeamKill", true)  -- this player can hurt their own side
npcModel:SetAttribute("Team", "Raider")   -- NPC team

CombatConfig

Team lists, armor timing and the hooks that run on every hit.

GunServer.Modules.CombatConfig
CombatConfig
return {
	ArmorRestoreDelay = 30,
	CivilianTeams = { "Civilian" },
	RaiderTeams = { "Raider" },
	RepublicTeams = { "Republic" },
	MaxReflections = 8,

	OnReflected = function(context) end,
	OnDamaged = function(context) end,
	OnKilled = function(context) end,
}
ArmorRestoreDelaySeconds without damage before armor refills.
CivilianTeamsTeam names treated as civilians.
RaiderTeamsTeam names treated as raiders.
RepublicTeamsTeam names that all count as one side. Add every Republic division here.
MaxReflectionsThe most times one bolt can bounce. After that it hits like a wall.

Names in these lists ignore capitals, so "republic" matches "Republic".

Hooks

OnDamaged and OnKilled receive the result table from Combat.Damage. They run after the hit, and an error inside one is printed without breaking combat.

Example
OnKilled = function(context)
	if context.TargetIsPlayer and context.AttackerPlayer then
		-- give the killer credits, update a leaderboard, etc
		print(context.AttackerPlayer.Name, "killed", context.TargetName)
	end
end,

OnDamaged = function(context)
	if context.ArmorBroken then
		print(context.TargetName, "lost their armor")
	end
end,

OnReflected runs each time a bolt bounces, with Part, Position, Normal, IncomingDirection, OutgoingDirection, Count, Attacker, AttackerPlayer, Source and BoltId.

Reflect & Block

Bolts pass through parts with CanCollide off. Two attributes change that.

Reflect = true

Bolts bounce off like a mirror, collision or not. Rockets with Reflectable = false hit it instead.

Block = true

Stops bolts even with CanCollide off, like an invisible energy shield. Sparks show where they stop.

Example
shieldPart.CanCollide = false
shieldPart:SetAttribute("Block", true)

mirrorPart:SetAttribute("Reflect", true)

Client events

Signals for the local player, each with the same context table as the server hooks.

GunReplicated.Client.CombatEvents
DamagedYou hit someone. Check ArmorDamage to see if armor took it.
KilledYou killed someone.
DamageTakenSomeone hit you.
DiedSomeone killed you.
LocalScript
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local CombatEvents = require(ReplicatedStorage.GunReplicated.Client.CombatEvents)

CombatEvents.Died:Connect(function(context)
	print("killed by", context.AttackerName)
end)

CombatEvents.Damaged:Connect(function(context)
	if context.ArmorDamage > 0 then
		print("hit their armor for", context.ArmorDamage)
	end
end)
